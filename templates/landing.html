This build is not yet code-signed, so Windows SmartScreen will warn you about it. We are not going to tell you to click through that warning — a wallet is exactly the kind of software where that habit gets people robbed. Verify the SHA-256 above before you run anything, and prefer the web wallet or the browser extension until signed builds ship. Signing and store distribution are in progress.

How to check the SHA-256 yourself

In PowerShell, run Get-FileHash .\WCAHT-Wallet-Setup-1.0.4.exe -Algorithm SHA256 and confirm the output matches the hash shown above. If it does not match, delete the file and tell us.

The macOS build has to be packaged on a Mac, which we are sorting out. Contact us if you want it early.
